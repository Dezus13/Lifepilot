# Glossary

## Case

Одна жизненная ситуация пользователя, связанная с исходным текстом, анализом, риском, статусом и планом действий.

## Analysis

Локальный результат обработки кейса: краткое объяснение, найденные факты, риск, приоритет, сроки и рекомендации.

## Risk Level

Оценка уровня риска кейса в интерфейсе. Используется как подсказка, а не как юридическое или финансовое заключение.

## Action Plan

Короткий список практических шагов, который помогает пользователю понять, что делать дальше.

## Case Engine

Общее название локальной бизнес-логики, которая анализирует кейс, определяет риск, приоритет, статус и план действий.

## LocalStorage Layer

Текущий рабочий слой хранения MVP. Сохраняет текущий кейс и локальную историю в браузере пользователя.

## Supabase Foundation Layer

Подготовленный Supabase client, TypeScript-тип строки `public.cases`, schema migration и функция `readSupabaseCases()`. В текущем MVP RLS включен, SELECT policy для anon role отсутствует, поэтому этот слой не является рабочим источником данных UI.

## MVP

Минимальная рабочая версия LifePilot, которая проверяет основной local-first сценарий создания, анализа и сохранения кейса.

## User Flow

Путь пользователя через продукт: создать кейс, получить анализ, посмотреть результат, получить план действий и открыть сохраненный кейс.
