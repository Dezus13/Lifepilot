# MVP Definition

## Цель MVP

MVP LifePilot нужен, чтобы проверить основной пользовательский сценарий: человек вставляет текст письма, документа или жизненной ситуации, получает понятное объяснение, уровень риска, приоритет, план действий и может вернуться к сохраненному кейсу.

Текущая версия остается local-first: пользовательский flow работает через `localStorage`, а Supabase Read Layer подготовлен как инфраструктурный слой и не является основным источником данных UI.

## Что входит в MVP

- Next.js приложение с App Router.
- Mobile-first интерфейс.
- Создание кейса из текстового ввода.
- Локальный анализ кейса.
- Risk Level.
- Priority Engine.
- Case Status Engine.
- Action Plan Engine.
- Сохранение текущего кейса и истории в `localStorage`.
- Экран истории кейсов.
- Детальный экран сохраненного кейса.
- Каноническая модель Case, описанная в [case-model.md](./case-model.md).
- Подготовленный Supabase Read Layer для `public.cases`.
- Документация specs, architecture, plans и testing.

## Что не входит в MVP

- Auth.
- Личные аккаунты.
- Запись кейсов в Supabase из UI.
- Удаление кейсов из Supabase.
- Real-time sync.
- Командная работа.
- Платные подписки.
- AI-агенты.
- Мобильное приложение.
- Корпоративные аккаунты.

## Критерии готовности MVP

MVP считается готовым, когда:

- пользователь может создать кейс;
- пользователь получает анализ кейса;
- Risk Level отображается в интерфейсе;
- Priority Engine формирует приоритет;
- Case Status Engine формирует статус;
- Action Plan Engine формирует план действий;
- кейс сохраняется в `localStorage`;
- сохраненный кейс открывается из истории;
- данные не передаются через URL;
- `npm run build` проходит без ошибок;
- документация соответствует фактической реализации.

## Post-MVP направления развития

Post-MVP направления не являются реализованными функциями текущего MVP.

Возможные направления после стабилизации MVP:

- подключение записи кейсов в Supabase;
- чтение пользовательской истории из Supabase;
- auth и личные аккаунты;
- политики доступа Supabase;
- синхронизация между устройствами;
- production security review.
