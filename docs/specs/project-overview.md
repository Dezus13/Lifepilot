# Обзор проекта LifePilot

## Что такое LifePilot

LifePilot — это мобильный помощник для людей, которые живут в Австрии и сталкиваются с письмами, документами, жильем и бытовой бюрократией на немецком языке.

Продукт помогает пользователю понять формальный текст, увидеть требования и подготовиться к следующему действию. В первой версии центральным объектом является кейс: письмо, документ, запрос, уведомление, договор или описанная пользователем ситуация.

LifePilot не заменяет юриста, переводчика или государственную консультацию. Система объясняет, структурирует и помогает подготовить ответ, но не принимает решения за пользователя.

Текущая учебная реализация работает локально в браузере: пользователь вводит текст, проходит экран анализа, видит демонстрационный результат и пример немецкого черновика. Пользовательский flow хранит кейсы в `localStorage`. Backend, auth, синхронизация и настоящая AI-логика пока не реализованы.

В проекте существует подготовленный Supabase read-only слой для таблицы `public.cases`. Он нужен как инфраструктурная основа, но пока не подключен к пользовательскому flow и не заменяет локальное хранение.

Спецификация модели Case описана в [case-model.md](./case-model.md). Этот документ является источником правды для структуры данных Case, статусов и жизненного цикла кейса.

## Цель проекта

Цель LifePilot — снизить стресс при работе с немецкими письмами и формальными ситуациями в Австрии.

Ключевой результат: пользователь вставляет текст, получает объяснение на русском языке, видит практичный план действий и при необходимости получает черновик ответа на немецком.

## Основная идея

LifePilot строится вокруг вопроса: «Что означает этот текст и что мне делать дальше?»

Для каждого кейса система должна показать:

- краткое объяснение простым языком;
- важные факты: даты, суммы, требования и риски;
- пошаговый план действий;
- немецкий ответ, если он нужен;
- предупреждение, если ситуация требует осторожности или специалиста.

## Единый MVP-сценарий

Базовый сценарий первой версии всегда линейный:

1. Пользователь вставляет текст письма, документа или ситуации.
2. LifePilot создает кейс.
3. Пользователь получает анализ.
4. Пользователь получает объяснение на русском языке.
5. Пользователь получает план действий.
6. Пользователь получает немецкий ответ.
7. Пользователь сохраняет кейс.

Все функции MVP должны поддерживать именно этот сценарий.

## Mobile-first подход

LifePilot проектируется в первую очередь для телефона.

Основной сценарий должен быть коротким:

1. Вставить текст письма, документа или ситуации.
2. Получить объяснение.
3. Посмотреть план действий.
4. Скопировать или адаптировать немецкий ответ.

В первой версии используется только текстовый ввод. Ограничения MVP описаны в `../plans/mvp-scope.md`.

## Границы ответственности

Система может:

- объяснять текст простыми словами;
- выделять требования, сроки и риски;
- предлагать общий порядок действий;
- готовить черновик немецкого ответа;
- показывать, какие данные нужно уточнить.

Система не должна:

- обещать юридически правильное решение;
- выдавать предположения за факт;
- скрывать неопределенность;
- отправлять документы без подтверждения пользователя;
- отправлять письма автоматически;
- принимать необратимые решения за пользователя.
