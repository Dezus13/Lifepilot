# MVP Checklist LifePilot

## Общая проверка

- [ ] Проект открывается без ошибок
- [ ] Все routes работают
- [ ] Нет пустых экранов
- [ ] Нет битых navigation links
- [ ] Mobile layout работает корректно

---

## Text Input

- [ ] Textarea принимает длинный текст
- [ ] Пустой текст показывает warning
- [ ] Слишком короткий текст показывает warning
- [ ] UI не ломается от большого текста

---

## Analysis Flow

- [ ] Анализ запускается корректно
- [ ] Определяется категория
- [ ] Определяется риск
- [ ] Генерируется структура ответа
- [ ] Генерируется немецкий черновик

---

## Safety

- [ ] High-risk warning отображается
- [ ] Пользователь видит disclaimer
- [ ] Пользователь подтверждает проверку черновика
- [ ] Нет ложного ощущения “официального документа”

---

## History

- [ ] Кейс сохраняется
- [ ] Reload страницы не удаляет историю
- [ ] Кейс можно открыть
- [ ] Кейс можно удалить

---

## UI / UX

- [ ] Loading states существуют
- [ ] Empty states существуют
- [ ] Buttons имеют disabled state
- [ ] Mobile spacing читаемый
- [ ] Нет layout shift

---

## MVP Ограничения

- [ ] Нет backend
- [ ] Нет auth
- [ ] Нет database
- [ ] Нет OCR
- [ ] Нет PDF parser
- [ ] Нет sync между устройствами
