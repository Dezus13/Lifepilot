# MVP checklist LifePilot

## Общая проверка

- [ ] Проект открывается без ошибок
- [ ] Все маршруты работают
- [ ] Нет пустых экранов
- [ ] Нет битых ссылок навигации
- [ ] Mobile-first layout работает корректно

---

## Ввод текста

- [ ] Поле ввода принимает длинный текст
- [ ] Пустой текст показывает предупреждение
- [ ] Слишком короткий текст показывает предупреждение
- [ ] UI не ломается от большого текста

---

## Сценарий анализа

- [ ] Анализ запускается корректно
- [ ] Определяется категория
- [ ] Определяется риск
- [ ] Генерируется структура ответа
- [ ] Показывается пример немецкого черновика

---

## Безопасность

- [ ] Предупреждение о риске отображается
- [ ] Пользователь видит ограничение: это не юридическая консультация
- [ ] Пользователь подтверждает проверку черновика
- [ ] Нет ложного ощущения “официального документа”

---

## История

- [ ] Кейс сохраняется
- [ ] Перезагрузка страницы не удаляет историю
- [ ] Кейс можно открыть
- [ ] Кейс можно удалить

---

## UI / UX

- [ ] Состояния загрузки существуют
- [ ] Пустые состояния существуют
- [ ] Кнопки имеют disabled state
- [ ] Mobile spacing читаемый
- [ ] Нет layout shift

---

## Ограничения MVP

- [ ] Нет backend
- [ ] Нет auth
- [ ] Нет database
- [ ] Нет OCR
- [ ] Нет PDF parser
- [ ] Нет настоящей AI-логики
- [ ] Нет синхронизации между устройствами
