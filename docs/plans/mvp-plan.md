# MVP Plan LifePilot

## Этап 1 — Базовый scaffold

Цель:
Создать чистую структуру Next.js проекта без лишней логики.

Что входит:
- app router
- базовые layouts
- mobile-first структура
- routing
- пустые страницы
- базовые ui-компоненты

Что НЕ входит:
- backend
- auth
- database
- OCR
- PDF parser
- sync между устройствами

---

## Этап 2 — Основной flow

Цель:
Пользователь должен пройти полный MVP-сценарий.

Flow:
1. Вставка текста
2. Анализ текста
3. Определение категории
4. Определение риска
5. Генерация структуры ответа
6. Генерация немецкого черновика
7. Проверка пользователем
8. Сохранение кейса

---

## Этап 3 — История кейсов

Что входит:
- список кейсов
- просмотр кейса
- удаление кейса
- local storage

---

## Этап 4 — UI polishing

Что входит:
- warning states
- empty states
- loading states
- mobile spacing
- accessibility
