# MVP Plan LifePilot

## Этап 1 — Базовая структура

Цель:
Создать чистую структуру Next.js проекта без лишней логики.

Что входит:
- app router
- базовые layout
- mobile-first структура
- маршрутизация
- пустые страницы
- базовые UI-компоненты

Что НЕ входит:
- backend
- auth
- database
- OCR
- PDF parser
- sync между устройствами
- Stripe
- billing
- payment flow
- подписки и тарифные лимиты

---

## Этап 2 — Основной сценарий

Цель:
Пользователь должен пройти полный MVP-сценарий.

Сценарий:
1. Вставка текста
2. Анализ текста
3. Определение категории
4. Определение риска
5. Генерация структуры ответа
6. Генерация немецкого черновика
7. Проверка пользователем
8. Сохранение кейса

---

## Этап 3 — История кейсов

Что входит:
- список кейсов
- просмотр кейса
- удаление кейса
- local storage

---

## Этап 4 — UI polish

Что входит:
- состояния предупреждений
- пустые состояния
- состояния загрузки
- mobile spacing
- accessibility

---

## После MVP

Платежи и монетизация рассматриваются только после проверки ценности основного сценария, auth, database и production validation.

Будущая модель может включать 3–5 бесплатных кейсов в месяц, индивидуальную подписку около 9.99 €/месяц, Family tier около 19.99 €/месяц и Pro tier около 49 €/месяц. Эти тарифы не реализуются в MVP.
