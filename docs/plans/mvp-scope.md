# Scope MVP LifePilot

## Назначение файла

Этот документ является главным источником ограничений MVP. Если другой документ противоречит этому файлу, сначала нужно обновить scope, затем остальные документы.

## MVP

В MVP входят только функции, которые поддерживают основной сценарий: вставить текст, получить анализ, понять документ, получить план действий, подготовить немецкий ответ и сохранить кейс.

Функции MVP:

- текстовый ввод письма, документа или ситуации;
- создание кейса;
- выбор категории кейса;
- анализ исходного текста;
- объяснение содержания на русском языке;
- выделение дат, сумм, требований и рисков;
- пошаговый план действий;
- генерация немецкого ответа;
- выбор тона немецкого ответа;
- плейсхолдеры для личных данных;
- история запросов;
- локальное сохранение кейсов;
- простые настройки;
- предупреждения о границах ответственности.

## Не входит в MVP

В первую версию не входят:

- AI voice;
- OCR;
- PDF parser;
- загрузка PDF;
- загрузка изображений;
- распознавание вложений;
- calendar sync;
- task manager;
- habits;
- analytics;
- multi-device sync;
- аккаунты пользователей;
- синхронизация между устройствами;
- автоматическая отправка писем;
- почтовые интеграции;
- полноценная юридическая база знаний;
- юридическая гарантия результата;
- командная или семейная работа;
- расширенные региональные сценарии по федеральным землям Австрии;
- поиск по истории;
- фильтры по категориям;
- архив кейсов;
- экспорт кейсов;
- удаление и восстановление кейсов;
- несколько вариантов немецкого ответа;
- шаблоны типовых писем.

## Post-MVP

Post-MVP включает функции, которые усиливают основной сценарий, но не нужны для проверки первой ценности.

Кандидаты:

- поиск по истории;
- фильтры по категориям;
- архив кейсов;
- экспорт кейсов;
- удаление и восстановление кейсов;
- несколько вариантов немецкого ответа;
- шаблоны типовых писем;
- более подробные объяснения по абзацам;
- справочник по типовым австрийским учреждениям;
- проверенные внешние ссылки;
- улучшенные настройки приватности.

## Future features

Future features — крупные расширения, которые нельзя включать в MVP.

Кандидаты:

- AI voice;
- OCR;
- PDF parser;
- calendar sync;
- task manager;
- habits;
- analytics;
- multi-device sync;
- аккаунты пользователей;
- почтовые интеграции;
- автоматическая отправка писем;
- региональные сценарии по федеральным землям Австрии;
- командная или семейная работа;
- полноценная юридическая база знаний.

## Принцип принятия решений по scope

Функция может войти в MVP только если она напрямую отвечает хотя бы на один вопрос:

- Что означает этот документ?
- Что пользователь должен сделать дальше?
- Как корректно ответить на немецком?
- Как сохранить результат, чтобы вернуться к нему позже?

Если функция не отвечает на эти вопросы, она переносится в Post-MVP или Future features.
