# Plans

## Назначение

Папка `docs/plans/` хранит планы работ LifePilot и делит их по статусу.

## Структура

- `active/` — текущие незавершенные планы.
- `completed/` — архив завершенных планов и завершенных planning-документов.

## Правила

- Новые планы создаются только в `docs/plans/active/`.
- После завершения план переносится из `active/` в `completed/`.
- В `active/` должно находиться минимальное количество планов.
- `completed/` является архивом завершенных работ и не используется как очередь текущих задач.
- Если план стал справочным документом после завершения этапа, он остается в `completed/`.
- Перед переносом плана нужно проверить его содержимое, ссылки и соответствие текущему состоянию проекта.
