# Список экранов MVP LifePilot

## Назначение файла

Этот документ перечисляет только экраны MVP, их назначение и действия пользователя. Данные, которые хранит система, описаны в `../specs/data-storage.md`.

## Линейный порядок экранов MVP

1. Главная.
2. Новый кейс.
3. Анализ.
4. Результат.
5. Черновик.
6. История.

Настройки остаются вспомогательным экраном и не нарушают основной сценарий.

Единые названия экранов в интерфейсе: Главная, Знакомство, Новый кейс, Анализ, Результат, Черновик, Риск, История, Безопасность, Ошибка.

## Главная

### Назначение

Быстрый старт нового анализа и переход к основным разделам.

### Основные элементы

- CTA `Новый кейс`;
- быстрые действия;
- обзор риска и статуса;
- примеры последних кейсов;
- переход в историю;
- переход в безопасность.

### Действия пользователя

- начать новый кейс;
- посмотреть примеры последних кейсов;
- перейти в историю;
- открыть безопасность.

## Новый кейс

### Назначение

Собрать текст письма, документа или описания ситуации.

### Основные элементы

- поле для текста;
- действие запуска анализа;
- сообщение об ошибке для пустого текста.

### Действия пользователя

- вставить текст;
- запустить анализ.

В текущем учебном MVP текст сохраняется локально в браузере.

## Экран результата анализа

### Назначение

Показать анализ, объяснение и следующий план действий.

### Основные элементы

- резюме;
- анализ исходного текста;
- объяснение;
- важные факты;
- предупреждения;
- план действий;
- переход к немецкому ответу;
- сохранение результата.

### Действия пользователя

- прочитать объяснение;
- посмотреть анализ;
- проверить важные факты;
- посмотреть план;
- перейти к ответу;
- сохранить результат.

## Экран генерации ответа

### Назначение

Подготовить черновик немецкого ответа.

### Основные элементы

- выбор тона;
- немецкий текст;
- русское пояснение;
- плейсхолдеры для личных данных;
- предупреждение перед использованием;
- действие копирования.

### Действия пользователя

- выбрать тон;
- получить ответ;
- проверить плейсхолдеры;
- скопировать текст;
- вернуться к анализу.

## История запросов

### Назначение

Показать сохраненные результаты и дать доступ к прошлым запросам.

### Основные элементы

- список запросов;
- краткое название или резюме;
- статус;
- пустое состояние.

### Действия пользователя

- открыть сохраненный результат;
- вернуться к списку;
- перейти к новому анализу.

## Настройки

### Назначение

Управлять простыми предпочтениями пользователя.

### Основные элементы

- язык объяснений;
- тон ответа по умолчанию;
- уровень детализации;
- настройка сохранения истории;
- информация о приватности;
- предупреждение о границах ответственности.

### Действия пользователя

- изменить тон ответа;
- изменить уровень детализации;
- включить или выключить сохранение истории;
- прочитать информацию о приватности.
