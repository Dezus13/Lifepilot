# Demo Script LifePilot

## 1. Открытие приложения

Действие: открыть главную страницу LifePilot.

Ожидаемый результат:

- пользователь видит mobile-first dashboard;
- есть быстрый вход в создание нового кейса;
- если история пуста, показывается безопасное empty state.

## 2. Создание кейса

Действие: открыть экран нового кейса и вставить текст письма, документа или ситуации.

Ожидаемый результат:

- поле принимает текст;
- пустой ввод не создает кейс;
- после нажатия `Анализировать` создается локальный `StoredCase`.

## 3. Анализ кейса

Действие: запустить анализ.

Ожидаемый результат:

- приложение показывает экран анализа;
- анализ выполняется локально;
- данные не отправляются в Supabase, backend или внешний API.

## 4. Просмотр результата

Действие: открыть экран результата после анализа.

Ожидаемый результат:

- отображается краткое объяснение;
- отображается уровень риска;
- отображается приоритет;
- отображается план действий;
- пользователь видит предупреждение о ручной проверке результата.

## 5. Просмотр истории

Действие: перейти на страницу истории.

Ожидаемый результат:

- созданный кейс отображается в локальной истории;
- карточка показывает preview текста, дату, уровень риска, статус и приоритет;
- поиск, фильтр и сортировка работают локально.

## 6. Повторное открытие кейса

Действие: открыть сохраненный кейс из истории.

Ожидаемый результат:

- detail view читает кейс из `lifepilot.caseHistory`;
- отображаются уровень риска, приоритет, краткое объяснение и план действий;
- `lifepilot.currentCase` не обязан изменяться;
- если кейс старый и содержит `sourceText`, локальный анализ может быть пересчитан на клиенте.
