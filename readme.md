# LifePilot

LifePilot — учебный MVP помощника для анализа писем и документов, а также подготовки безопасного черновика ответа.

## MVP features

- создание нового кейса через textarea;
- локальное сохранение текста в `localStorage`;
- экран анализа;
- результат с кратким анализом, риском и рекомендациями;
- пример немецкого черновика;
- mobile-first интерфейс.

## Технологии

- Next.js
- TypeScript
- CSS
- `localStorage`

## Как запустить

```bash
npm install
npm run dev
```

## Ограничения MVP

- без backend;
- без database;
- без OCR/PDF parser;
- без настоящей AI logic;
- немецкий ответ является примером для ручной проверки.

## Статус

Учебный MVP / prototype.
