# LifePilot

LifePilot — учебный MVP помощника для писем и документов. Проект помогает вставить текст, получить краткий локальный разбор, увидеть уровень риска и открыть пример немецкого черновика ответа.

LifePilot не является юридической консультацией и не отправляет письма автоматически. Все факты и формулировки нужно проверять вручную.

## Что работает сейчас

- создание нового кейса через поле ввода текста;
- сохранение текста текущего кейса в `localStorage`;
- экран анализа с коротким состоянием загрузки;
- результат с кратким анализом, уровнем риска и рекомендациями;
- пример немецкого черновика для ручной проверки;
- mobile-first интерфейс.

## Технологии

- Next.js
- TypeScript
- CSS
- `localStorage`

## Как запустить

```bash
npm install
npm run dev
```

После запуска откройте локальный адрес из терминала, обычно `http://localhost:3000`.

## Ограничения MVP

- без backend;
- без auth;
- без database;
- без OCR/PDF parser;
- без настоящей AI-логики;
- без автоматической отправки писем;
- немецкий ответ является примером, а не финальным юридическим письмом.

Данные текущего кейса хранятся только в браузере. Если очистить данные браузера, сохраненный текст может пропасть.

## Статус

Учебный MVP / prototype.
