# Инструкции для агентов LifePilot

## Язык проекта

Вся документация и комментарии пишутся только на русском языке.

## Порядок работы

Сначала проверять существующую структуру и документацию, затем вносить изменения.

## Разделы документации

- Specs: `docs/specs/`
- Plans: `docs/plans/`
- Design: `docs/design/`
- Architecture: `docs/architecture/`
- Testing: `docs/testing/`

## Правила

- Не создавать случайные или лишние файлы.
- Если specs не хватает, сначала обновить specs, потом писать код.
- Перед push сначала проверить plans и структуру проекта.
